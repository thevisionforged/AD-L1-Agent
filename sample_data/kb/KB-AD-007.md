# KB-AD-007: Add a network printer
Category: Printing | Subcategory: Printer setup
Applies to: Office printers on the CORP print server | Last reviewed: synthetic sample

## [s1] Add a printer
1. Open Settings > Bluetooth & devices > Printers & scanners > Add device.
2. If the printer is not listed, choose "Add manually" and enter \\print01.corp.example.com\<printer name>. The printer name is on the label on the front of the printer.
3. Print a test page.

## [s2] When to escalate
- "Windows cannot connect to the printer" with access denied, or the printer is offline for everyone. Escalate to EUC-L2 Desktop Support with the printer name and floor.
