# KB-AD-008: Request or install software
Category: Software | Subcategory: Software request
Applies to: Managed Windows and macOS devices | Last reviewed: synthetic sample

## [s1] Install approved software
1. Open Company Portal (Windows) or Self Service (macOS).
2. Search for the application and select Install. No admin rights are needed.

## [s2] Software that is not in Company Portal
- Raise a software request with the product name, version and business reason. Licensed software needs manager approval.
- Users do not get local administrator rights to install software themselves.
