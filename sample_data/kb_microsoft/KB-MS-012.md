# KB-MS-012: Set up Microsoft Authenticator for your work account
Category: Password & MFA | Subcategory: MFA
Audience: end user
Source: https://support.microsoft.com/en-us/account-billing/set-up-the-microsoft-authenticator-app-as-your-verification-method-33452159-6af9-438f-8f82-63ce94cf3d29

## [s1] Add your work account with a QR code
New phone but you still have the old phone, or another working sign-in method? You can do this yourself; no ticket is needed.
1. On your computer, sign in to the Security info page at https://mysignins.microsoft.com/security-info.
2. Select Add sign-in method and choose Authenticator app.
3. If the app is already on your phone, select Next to show a QR code.
4. In Microsoft Authenticator on the phone, add an account, choose Work or school account, then Scan a QR code.
5. If the camera cannot scan the code, choose the option to enter the code manually on the phone and type the code and URL shown on your PC.

## [s2] Only if you have NO working sign-in method (phone lost, stolen or wiped)
- You cannot add a new phone without a working method. Contact the service desk: after verifying your identity they can remove the old phone and give you a Temporary Access Pass to register the new one (KB-AD-003#s3).
